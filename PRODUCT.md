# DNA · The Choice

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

An interactive exhibit adapted from Parth Pawar’s original DNA speculative design project. Visitors inspect two fictional pharmaceutical offers, make an initial decision, and reconsider it under five independent conditions.

## Capabilities and Constraints

The approved experience has six decisions, reversible navigation, optional scientific context, private notes, a personal comparison matrix, and text/print exports. Responses stay in memory only. No accounts, payments, analytics, or response submission. Preserve the original photography and identify all treatment offers as fictional.

## Brand Commitments

The user chose a bright gallery that feels tactile and immersive. Physical objects lead; interface controls recede. Earlier references were Cursor and Paper for premium precision. The user rejected the first implementation as a poor experience and asked to build the design system first.

## Evidence on Hand

Five original artifact photographs are in dist/assets. The original project is https://designwhich.works/dna-speculative/. Scientific context links to the National Institute on Aging. No audience statistics or personality scores are available or intended.

## Current Scope

Apply the bright gallery system to the complete exhibit. Shared choice controls, photography, reversible progress navigation, reflections, private notes, matrix revisions, and exports form one experience.
